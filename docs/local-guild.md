# 本地公会与存档

本地公会数据保存在账号数据库的 `guilds` 节点，账号自身保留公会 UID 和个人捐赠记录。创建公会沿用游戏规则：账号等级 15，消耗 1000 钻石。

当前支持建会、搜索与加入、审核、成员和会长管理、公告、签到、捐赠、公会聊天、福利点购买、重命名、延迟解散与撤回，以及公会 Boss 训练。公会币可以在现有公会商店兑换商品。

备份公会时，请在用户管理页面导出完整的数据库 JSON。单账号 profile 的导出或复制只备份账号，不能保留多人公会及会长身份。导入或复制账号后，如果原公会不存在，或新账号 UID 不在原公会成员列表中，服务会将旧关联保存到 `archivedGuildMembership` 并清理公会引用，使账号能够重新创建或加入本地公会。完整数据库恢复后，原有成员关系保持有效。

Boss 训练使用所选的 16 人 raid 编队和真实游戏关卡，不消耗世界 raid 次数，不发放正式合作战奖励。正式合作战的 arena 神器、多人伤害与积分累计、赛季领奖，以及福利 buff 的实际效果尚未接入；相关请求返回错误，不扣除费用。

验证命令：`node tools/check-local-guild.js`。这项检查验证本地逻辑和协议，不代表 Android 真机验收。
